# 1. Complete Feature List

## A. YouTube Task System (Phase 1 – Core)

- Admin adds YouTube videos (URL, title, keywords, thumbnail, reward type & amount)
- Multiple reward types per video:
  - Per Time (e.g. 10 coins per 60 seconds)
  - Watch All (fixed coins for completing the video)
  - Target (watch up to X minutes or X% → fixed coins)

- User sees list of available video tasks (thumbnail + title)
- Randomized search instruction per user (keywords / exact title / phrases)
- Full in-app browser (free browsing like Chrome)
- Auto-detection when user lands on the correct video ID
- Second-by-second tracking (play, pause, seek, time watched)
- Progress is saved (user can leave and continue later)
- Only new watched seconds are rewarded
- Cannot earn twice after video is completed
- Watching non-approved videos = no reward

## B. User Account

- Register / Login
- Profile (avatar, username, bio)
- Account settings
- Change password
- Delete account

## C. Membership System

- Free & Paid plans
- Feature gating
- Subscribe / Upgrade / Cancel
- Payment integration

## D. Wallet & Coins

- Coin balance
- Full transaction ledger
- Earn & Spend history

## E. Rewards Engine

- Configurable reward rules
- Coins for watching, daily login, tasks, referrals, etc.

## F. Referral System

- Unique referral code/link
- Rewards for both sides
- Referral history & anti-abuse

## G. Engagement Features

- Daily tasks / Quests
- Watch streaks
- Achievements / Badges
- Push notifications
- Leaderboard (optional)

## H. Content

- Watch history
- Continue watching
- Favorites

## I. Admin Panel

- Manage users

- Manage wallet & rewards
- View analytics
